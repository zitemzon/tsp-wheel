# 03 — ฮาร์ดแวร์ การต่อสาย และการ flash

## 1. ของที่ใช้

| ชิ้น | รายละเอียดจากบอร์ดจริง |
| :-- | :-- |
| บอร์ดหลัก | `Router_V2.0` ติดตั้งโมดูล **ESP32-S3-N16R8** (WiFi+BT, flash 16MB, PSRAM 8MB OPI) |
| จอ | `LCD Adapter_V1.0` + พาเนล TFT SPI 240×320 (2.4″/2.8″) ต่อผ่าน FPC |
| สายสัญญาณ | IDC 10 เส้น → ป้ายบนบอร์ดจอ: `SDA · SCL · CS · RS · RST · BLK · VCC · GND` |
| อื่น ๆ บนบอร์ด | RJ45 `HR911105A`, USB-C, ปุ่ม 2 ตัว, ขั้ว JST — ไม่ได้ใช้ในเฟิร์มแวร์รุ่นนี้ |

> **หมายเหตุเรื่อง Ethernet** — ESP32-S3 ไม่มี MAC ในตัว การใช้ RJ45 ต้องผ่านชิป SPI (เช่น W5500)
> เฟิร์มแวร์รุ่นนี้ใช้ **WiFi อย่างเดียว** ถ้าจะใช้สาย LAN ต้องยืนยันรุ่นชิปบนบอร์ดก่อนแล้วค่อยเพิ่ม `ETH.begin()`

## 2. ผังขา — ค่าจริงของบอร์ด Router_V2.0

ยืนยันแล้วจาก `User_Setup.h` ของ TFT_eSPI ที่ใช้กับบอร์ดนี้อยู่ ตั้งไว้เป็นค่าเริ่มต้นใน `config.h.example` แล้ว

| สัญญาณจอ | GPIO | ชื่อใน TFT_eSPI |
| :-- | :-: | :-- |
| SDA (MOSI) | **6** | `TFT_MOSI` |
| SCL (SCLK) | **7** | `TFT_SCLK` |
| CS | **8** | `TFT_CS` |
| RS (DC) | **12** | `TFT_DC` |
| RST | **5** | `TFT_RST` |
| BLK | **9** | `TFT_BL` · `TFT_BACKLIGHT_ON HIGH` → `BL_ON_HIGH 1` |
| MISO | ไม่ต่อ | `TFT_MISO -1` — โค้ดตั้ง `pin_miso = -1` |
| VCC / GND | 3.3V / GND | ไฟ backlight ~60–100 mA ต้องมาจากราง 3.3V ที่จ่ายไหว |

ขาชุดนี้ปลอดภัยกับ N16R8: ไม่มีตัวไหนอยู่ในช่วง **GPIO 26–37** ที่ผูกกับ flash/PSRAM แบบ OPI
(แตะแล้วบูตไม่ขึ้น) และไม่ชน strapping pin ของ ESP32-S3 (**0 / 3 / 45 / 46**)
ถ้าจำเป็นต้องย้ายขาในอนาคต ให้อยู่ในช่วง GPIO 4–18 หรือ 38–42

`BL_ON_HIGH 1` แปลว่าค่า PWM สูง = สว่าง (ตรงกับ `TFT_BACKLIGHT_ON HIGH`)
ถ้าบอร์ดรุ่นอื่นกลับขั้ว ให้ตั้งเป็น 0 แล้ว LovyanGFX จะกลับค่าให้เอง

## 3. ตั้งค่า driver IC ให้ถูกรุ่น

สายมี 8 เส้น ไม่มี MISO → อ่าน ID จากจอไม่ได้ ต้องกำหนดเองใน `config.h`

| อาการที่เห็น | แก้ที่ |
| :-- | :-- |
| จอขาว/ดำสนิท ไม่มีภาพ | เช็ค RST, CS, DC ก่อน แล้วลองสลับ `PANEL_ILI9341` เป็น 0 (= ST7789) |
| ภาพติดสีกลับ (ขาวเป็นดำ) | `TFT_INVERT` → 1 (พาเนล ST7789 ส่วนใหญ่ต้องเปิด) |
| ภาพเลื่อนไปข้าง/มีแถบขอบ | ปรับ `offset_x` / `offset_y` ในคลาส `LGFX` (`ui_pages.cpp`) |
| มีเส้นรบกวน/ภาพพัง | ลด `TFT_SPI_HZ` เหลือ 27000000 หรือ 20000000 |
| ภาพแนวตั้ง | `TFT_ROTATION` 1 หรือ 3 (หน้าจอออกแบบไว้สำหรับแนวนอน 320×240) |

## 4. ขั้นตอน flash

```bash
cd monitor/firmware
cp src/config.h.example src/config.h        # แล้วแก้ WiFi / URL / token / ขา
pio run                                      # คอมไพล์
pio run -t upload                            # แฟลชผ่าน USB-C
pio device monitor                           # ดู log 115200
```

log ที่ควรเห็นเมื่อทุกอย่างปกติ:

```
[net] อัปเดตแล้ว hash=1a2b3c4d วันนี้=12450 เดือน=186500
[net] ข้อมูลไม่เปลี่ยน            <- รอบถัดไปที่ยอดยังไม่ขยับ
```

ถ้าดึงข้อมูลไม่ได้ติดกัน 5 ครั้ง บอร์ดจะรีสตาร์ตตัวเองอัตโนมัติ

## 5. งบหน่วยความจำและเวลาเฟรม

| รายการ | ค่า |
| :-- | :-- |
| sprite 3 ชั้น (ปัจจุบัน/ถัดไป/ผสม) | 320×240×2B × 3 = **450 KB** ใน PSRAM |
| JSON buffer | ~4 KB ใน heap |
| เวลา crossfade | 8 สเต็ป × (blend ~12 ms + push SPI ~30 ms) ≈ **340 ms** |
| ถ้าอยากให้นุ่มขึ้น | เพิ่ม `FADE_STEPS` เป็น 12 (fade ~500 ms) |
| ถ้าจอกระตุก | ลด `FADE_STEPS` เหลือ 6 หรือลด `TFT_SPI_HZ` |

การ fade ทำด้วยการผสมค่าสี RGB565 ในบัฟเฟอร์ **ไม่ใช่การหรี่ backlight**
ขา BLK สงวนไว้สำหรับหรี่จอกลางคืน (`BL_NIGHT` ช่วง `NIGHT_START_HOUR`–`NIGHT_END_HOUR`)

## 6. เรื่องฟอนต์ไทย (ค้างไว้เป็น P2)

ค่าเริ่มต้น `HAS_THAI_FONT 0` → ป้ายกำกับเป็นภาษาอังกฤษสั้น ๆ ส่วน **ตัวเลขทุกตัวแสดงครบปกติ**

ถ้าจะใส่ไทยจริง มี 2 ทาง:

1. **แปลง TTF เป็นฟอนต์ GFX** (เช่น Sarabun ช่วง U+0E00–U+0E7F ด้วย `fontconvert` ของ Adafruit)
   — เร็วแต่ **สระบน/ล่างจะไม่ลอยเข้าที่** เพราะ GFX วางกลิฟเรียงทีละตัว ไม่มี shaping
   ใช้ได้กับคำที่ไม่มีสระซ้อน เช่น "วันนี้" จะเพี้ยน
2. **พรีเรนเดอร์ป้ายเป็นบิตแมป** (แนะนำ) — ป้ายในจอมีแค่ ~15 คำและชื่อสาขา 8 ชื่อ
   เรนเดอร์จาก Kanit เป็น XBM ขาวดำตอน build แล้วฝังเป็น array
   ได้ตัวอักษรถูกต้อง 100% กินพื้นที่ ~20–30 KB และไม่ต้องมี shaping engine บนบอร์ด

ไม่ว่าทางไหน อย่าลืมเผื่อความกว้างป้ายภาษาไทยมากกว่าอังกฤษ ~20% เวลาเช็ค layout ใน `preview.html`
