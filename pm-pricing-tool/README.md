## ข้อผิดพลาดที่แก้จากเวอร์ชัน 1
1. **ต้นทุนเครื่องอบไม่ถูกใช้** — สูตรต้นทุนแพ็กเกจใช้ค่าเฉลี่ย 325 บาทกับทุกเครื่อง ทั้งที่ไฟล์ระบุเองว่าเครื่องอบหนักกว่า 1.27 เท่า (413 บาท) → GM สูงเกินจริง 4-7 จุด
2. **GM ของดีลในชีต 3 สูงเกินจริง** — นับทุกเครื่องเป็นเครื่องซัก และไม่นับต้นทุนเดินทางส่วนเกินที่เก็บเงินเป็นรายได้
3. **ขั้นส่วนลด 6 ชุดคู่ขึ้นไปขาดทุน** — ลด 25% + แถมรอบฟรี 1 รอบพร้อมกัน และตารางส่วนลดเดิมไม่มีคอลัมน์ต้นทุน/GM ให้ตรวจ
4. **ค่าแรงซ่อมด่วนไม่มีต้นทุน** — Care Pro ให้ฟรีไม่จำกัดแต่ตั้งเผื่อแค่ 1,000 บาทที่ระบุว่าเป็นค่าท่อ Flex
5. **ชีต 4 ไม่มีคอลัมน์สถานะ** ตามที่คู่มือในไฟล์อ้างไว้ และสูตรรอบคงเหลือไม่นับรอบฟรีของลูกค้า 6 ชุดคู่ขึ้นไป

## เป้า Gross Margin (v2.1)
เปลี่ยนจากเป้าเดียว 50% เป็น **2 ระดับ** ให้ตรงกับราคาที่ตลาดจ่ายจริง
- **Floor 35%** — ต่ำกว่านี้ไม่ควรรับงาน
- **Target 45%** — ระดับที่ราคาป้ายควรอยู่

ที่มา: ราคาตลาด CODE CLEAN 600 บาท/เครื่อง/ครั้ง = 1,200 บาท/ชุดคู่/รอบ เทียบต้นทุน 738 บาท → GM ที่ตลาดจ่ายจริงอยู่ราว **38.5%**
(ตัวเลขนี้คำนวณสดอยู่ในชีต 1 แถวล่างสุด)

## ความสามารถที่เพิ่ม
- ราคา 2 ระดับอัตโนมัติ: ขั้นต่ำ (Floor) และเป้าหมาย (Target) — ชีต 2 คอลัมน์ I/J, ชีต 3 แถว 43-44
- เพดานส่วนลดต่อแพ็กเกจ ทั้งกรณีมีและไม่มีรอบบริการฟรี (ชีต 2)
- บันไดส่วนลดที่แนะนำ 0/5/10/12% (ตัดรอบฟรีออก) เทียบกับบันไดเดิมแบบเคียงข้างกัน
- เพดานส่วนลดสูงสุดที่ให้ได้ขณะต่อรอง (ชีต 3 แถว 45) และบรรทัดแนะนำฐานต้นทุนตามจำนวนเครื่อง
- เลือกฐานต้นทุนได้: ค่าเฉลี่ย / งานกระจุกจุดเดียว / งาน Route หลายจุด
- ตาราง GM ของทุกขั้นส่วนลด ทั้ง 3 แพ็กเกจ พร้อมแถบสีแดงเมื่อขาดทุน
- ตรวจ GM ของดีลชำระล่วงหน้า 3 ปี
- คอลัมน์สถานะรอบ PM พร้อมสีเตือน (เกินกำหนด / ใกล้ถึงกำหนด / ปกติ)
