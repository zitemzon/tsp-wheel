# การคำนวณ ROI ร้านสะดวกซัก — Samsung Commercial

เทมเพลต Excel สำหรับประเมินความคุ้มค่าการลงทุนเปิดร้านสะดวกซัก (Laundromat)
อิงราคาและสเปกจริงจากเอกสาร Samsung Commercial Franchise (ก.ย. 2026) โครงสร้างต่อยอดจากฟอร์ม Laundry Crew ROI Model

## ไฟล์
| ไฟล์ | คำอธิบาย |
|---|---|
| `การคำนวณROI_ร้านสะดวกซัก_Samsung_Commercial_v2.1.xlsx` | ไฟล์เทมเพลตพร้อมใช้งาน (11 ชีต, ~1,720 สูตร) |
| `build_roi_template.py` | สคริปต์สร้างไฟล์ (openpyxl) — แก้ที่นี่แล้ว re-generate เมื่อต้องออกเวอร์ชันใหม่ |

## โครงสร้างชีต
1. `0_README` — คู่มือ, ที่มาตัวเลข, สิ่งที่ต้องเติมก่อนใช้จริง
2. `A_INPUT` — ช่องกรอก 8 หมวด (โครงการ / ตลาด / แพ็กเกจ / CAPEX / Operation / รายได้เสริม / OPEX / การเงิน-ภาษี)
3. `B_PACKAGES` — สเปกเครื่อง + แพ็กเกจ S/M/L/CUSTOM (ราคาจริง) + CAPEX นอกแพ็กเกจ + อุปกรณ์เสริม
4. `C_CALC` — เครื่องคำนวณ 9 ส่วน (capacity → รอบที่ขายได้ → รายได้ → ต้นทุน → P&L → KPI → health check)
5. `D_DASHBOARD` — KPI + งบกำไรขาดทุน + คำเตือนอัตโนมัติ
6. `E_CASHFLOW` — กระแสเงินสด 60 เดือน + NPV + IRR + ตารางผ่อนเงินกู้
7. `F_SERVICE` — ประกันในแพ็กเกจ + แพ็กเกจ PM รายปี (Care/Care+/Care Pro) + เปรียบเทียบค่าบริการระบบ 2 ทางเลือก
8. `G_SCENARIO` — Worst/Base/Best + ตารางความอ่อนไหว 2 ทาง
9. `H_LOCATION_SCORE` — ให้คะแนนทำเล 12 เกณฑ์ → GO / HOLD / NO-GO
10. `I_PRINT_VIEW` — สรุปการลงทุน A4 1 หน้า สำหรับเสนอลูกค้า
11. `Z_LISTS` — รายการ dropdown (ซ่อน)

## ข้อมูลที่ยืนยันแล้ว (v2.0)
- ราคาแพ็กเกจรวม VAT: S 3 คู่ = 699,000 | M 4 คู่ = 799,000 | L 5 คู่ = 899,000 บาท
- สเปก: ซัก 18 kg / 36 นาที · อบแก๊ส 14 kg / 45 นาที · ทนทาน 30,000 รอบ
- ประกันเครื่อง 3 ปี · กล่องหยอดเหรียญ 1 ปี · ระบบ I'M CONTROL ฟรี 1 ปี
- ค่าบริการระบบหลังปีแรก: 100 บาท/เครื่อง + 700 บาท/สาขา (7 เครื่องขึ้นไป) + 8,000 บาท/ปี — ยกเว้นทั้งหมดถ้าเปิดสแกน PromptPay 3%
- ราคาอุปกรณ์เสริมจากตารางสรุปราคา (กล่องไซด์บาร์ / เครื่องแลกเหรียญ / ตู้จำหน่ายสินค้า)
- แพ็กเกจ PM รายปี: Care 2,600 (2 รอบ) · Care+ 4,900 (4 รอบ) · Care Pro 7,900 (4 รอบ + ฟรีค่าแรงซ่อม) ต่อชุดคู่/ปี ก่อน VAT
- Single PM: ซัก 650 / อบ 850 บาท/เครื่อง/ครั้ง · ส่วนลด 2-3 ชุดคู่ 10% · 4-5 ชุดคู่ 20% · 6+ ชุดคู่ 25%
- ค่าเดินทางฟรีในรัศมี 30 กม. เกินคิด 12 บาท/กม. · ชำระล่วงหน้า 3 ปี ลด 15% · ต่ออายุปรับไม่เกิน 10%/คราว

## ตัวเลขที่ยังต้องยืนยัน
ค่าไฟ-น้ำ-แก๊สต่อรอบ, ราคาขายต่อรอบ, จำนวนครั้งเรียกซ่อมด่วน/ปี, CAPEX นอกแพ็กเกจ และ % utilization จริง
