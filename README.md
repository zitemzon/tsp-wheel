# วงล้อเสี่ยงโชค Toy Station Plus+ (v2) — คู่มือติดตั้ง

## A. อัปเดตจาก v1 → v2 (ถ้าติดตั้งไปแล้ว)

1. Apps Script → เปิด `Code.gs` → **ลบทั้งหมด** แล้ววางเนื้อหาไฟล์ `Code.gs` ใหม่
2. เปิดไฟล์ HTML `spin` และ `admin` → ลบทั้งหมด → วางเนื้อหาใหม่ (`verify` ไม่เปลี่ยน)
3. รันฟังก์ชัน **`setup`** อีกครั้ง — ปลอดภัยกับข้อมูลเดิม 100% ระบบจะเติมเฉพาะ config ใหม่ 8 ตัว ไม่แตะรางวัล/สาขา/log
4. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**

## B. Landing Page (ให้แชร์แล้วมีภาพ + แคปชั่นสุ่ม)

โฟลเดอร์ `landing/` มี 8 ไฟล์ — `1.html`–`4.html` และ `og-1.png`–`og-4.png`
ระบบจะ**สุ่ม**ว่าลูกค้าแต่ละคนแชร์ไฟล์ไหน → ได้ภาพและหัวเรื่องต่างกัน 4 แบบ

### วิธีขึ้น GitHub Pages (ฟรี ~10 นาที)

1. สมัคร/เข้า github.com → **New repository** → ชื่อ `tsp-wheel` → เลือก **Public** → Create
2. กด **Add file → Upload files** → ลากไฟล์ทั้ง 8 ไฟล์ในโฟลเดอร์ `landing/` ใส่ → Commit
3. **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที จะได้ URL: `https://ชื่อผู้ใช้.github.io/tsp-wheel`

### แก้ 2 จุดในไฟล์ 1.html–4.html (ทุกไฟล์)

| หา | แทนที่ด้วย |
|---|---|
| `__BASE__` (มี 2 จุดต่อไฟล์) | `https://ชื่อผู้ใช้.github.io/tsp-wheel` |
| `https://script.google.com/macros/s/XXXXXXXXXXXX/exec` | URL เว็บแอปจริงของคุณ |

> ⚠️ `og:image` และ `og:url` **ต้องเป็น URL เต็มขึ้นต้น https://** เท่านั้น ใส่ path แบบสั้นจะไม่ขึ้นรูป

### ตั้งค่าในหน้า Admin

แท็บ **ระบบแชร์** → ช่อง `URL โฟลเดอร์ Landing Page` ใส่ `https://ชื่อผู้ใช้.github.io/tsp-wheel` → จำนวนไฟล์ = `4` → บันทึก

### ล้างแคช Facebook (ทำครั้งเดียว สำคัญ)

เอาลิงก์ทั้ง 4 ไปวางที่ https://developers.facebook.com/tools/debug/ แล้วกด **Scrape Again** ทีละอัน
ถ้าไม่ทำ ครั้งแรกที่มีคนแชร์ FB อาจยังไม่ดึงรูป

## D. ระบบบังคับแชร์ — ทำงานอย่างไร

```
ลูกค้ากด "แชร์กิจกรรมบน Facebook"
   ↓
server ออก share token + จดเวลาเริ่ม (t0)  ← เก็บใน CacheService อายุ 30 นาที
   ↓
เว็บคัดลอกแคปชั่นให้อัตโนมัติ + เปิดหน้า sharer.php
   ↓
ลูกค้ากลับมากด "ฉันแชร์เรียบร้อยแล้ว"
   ↓
server เช็ค (now - t0) >= 8 วินาที  → ตั้ง token.ok = true
   ↓
apiSpin ตรวจ token.ok + เบอร์/สาขาต้องตรงกัน จึงจะหมุนได้
```

**ปิดช่องโหว่ v1:** เดิมส่ง `shared=true` เป็น boolean จาก client ใครเปิด console ก็ปลอมได้
ตอนนี้ต้องมี token ที่ server ออกให้และผ่านเงื่อนไขเวลาเท่านั้น

### ⚠️ ข้อจำกัดที่ต้องยอมรับ

| ข้อ | สถานะ |
|---|---|
| ใส่แคปชั่นอัตโนมัติในช่องโพสต์ FB | **ทำไม่ได้** — Meta ปิดตั้งแต่ 2011 ระบบจึงคัดลอกให้แทน ลูกค้ากดวางเอง |
| ตรวจว่าโพสต์จริงหรือกดปิดทิ้ง | **ทำไม่ได้** — ต้องใช้ FB Login + permission `user_posts` ที่ Meta ไม่อนุมัติ |
| ภาพขึ้นตอนแชร์ | ทำได้ ผ่าน Landing Page เท่านั้น (Apps Script ใส่ OG tag ไม่ได้) |

ถ้าต้องการบังคับ 100% ให้ตั้ง `share_mode` เป็น SOFT ไว้ตามเดิม แล้วเพิ่มกติกาหน้าร้าน:
**ลูกค้าโชว์โพสต์ให้พนักงานดู → พนักงานจึงกดวงล้อให้** (ควบคุมด้วยคน ไม่ใช่ระบบ)

## E. Auto-fit ตัวอักษรบนวงล้อ

ระบบคำนวณพื้นที่ของแต่ละช่องแล้วลดขนาดฟอนต์ให้พอดีอัตโนมัติ

| ข้อจำกัด | สูตร |
|---|---|
| แนวรัศมี | `outer - inner - padding` (outer = 0.925R, inner = 0.30R) |
| แนวขวาง (คอร์ด) | `2 × Rmid × sin(seg/2) × 0.82` |

ไล่ลดฟอนต์จาก 38px → 15px ถ้ายังไม่พอ จะตัดเป็น 2 บรรทัดที่ช่องว่างใกล้กึ่งกลางที่สุด
ปรับภาพรวมได้ที่ Admin → ตั้งค่ากิจกรรม → **ขนาดตัวอักษรบนวงล้อ** (0.7–1.4)
